# 逾期协商月供测算器

> Debt Negotiation Monthly Payment Calculator

一站式估算合规协商空间，识别反催收灰产话术红线。

**🔗 在线体验**：https://nic-wang.github.io/debt-negotiation-calculator/

---

## 特性

- **31 家头部金融机构内置政策库**：信用卡 13 家 / 银行贷款 5 类 / 持牌消金 7 家 / 互联网平台 6 家
- **合规公式实时计算**：基于《商业银行信用卡业务监督管理办法》第七十条，N ≤ 60 期
- **灰产红线识别**：低于合规地板价 50% 自动告警
- **本地隐私计算**：所有数据仅在浏览器本地处理，不上传任何后端

## 计算公式

```
M = [P + I₀ × (1−α) − P × β] / N        ← 协商后月供
M_floor = P / N_max                       ← 合规月供地板价
```

其中：
- `P` 本金
- `I₀` 已产生利息+违约金
- `α` 利息减免比例 (0–1)
- `β` 本金减免比例 (0–1，常见 0)
- `N` 协商分期期数
- `N_max` 该机构允许的最长期数

## 政策口径

| 产品类型 | 法律 / 监管依据 | N_max | α 区间 |
|---|---|---|---|
| 信用卡逾期 | 《商业银行信用卡业务监督管理办法》第 70 条 | 60 期 | 70%–100% |
| 银行个人贷款 | 银保监会延期/重组政策 | ≤120 期 | 30%–60% |
| 持牌消费金融 | 机构内部政策 | 36 期 | 30%–80% |
| 互联网借贷平台 | 平台自愿 | 24–36 期 | 0%–50% |

## 免责声明

本工具输出为协商空间的**合规上限估算**，不构成具体银行批复承诺。任何低于"P / N_max"地板价 50% 以上的"协商方案"，均应高度警惕反催收灰产风险（参见银保监会 2022 年《关于防范金融领域侵害消费者合法权益相关风险的提示》）。
